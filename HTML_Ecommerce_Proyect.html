🛒 E-Commerce End-to-End Data Pipeline

Project Technical Defense & Architecture Overview
Engineer: Martín Flores | Platform: Databricks Lakehouse & Delta Lake

1. Executive Summary & Business Impact

This project addresses the challenge of unformatted, fragmented transactional e-commerce data. By engineering an end-to-end automated pipeline on Databricks using the Medallion Architecture, raw unstructured logs were transformed into a highly reliable Kimball Star Schema for executive analytics.

  • Data Integrity: 100% financial and volume reconciliation between raw intake and Gold tables.
  • Idempotency: Fault-tolerant execution preventing duplication upon job retries.
  • Analytics-Ready: Pre-aggregated dimensions and metrics powering downstream BI dashboards.

2. Medallion Architecture Breakdown

🟤 Bronze Layer (Raw Storage)

Preserves full source data history in append-only Delta tables without applying schema modifications, ensuring strict auditability.

⚪ Silver Layer (Cleansed & Enriched)

Applies explicit data type casting (DECIMAL, INT, DATE), trims strings, removes corrupted records, and generates deterministic surrogate keys using MD5 hashing.

🟡 Gold Layer (Kimball Dimensional Model)

Structures clean data into a Star Schema featuring fact_sales linked to dim_customers, dim_products, and dim_date.
